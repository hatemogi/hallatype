# hallatype

한글 비트맵 글꼴 편집기(`/`), 키별 자소 마스크 편집기(`/masks`), 타자 연습 앱(`/practice`).

## 목표

* 프런트 기술 연습: TypeScript, Vue
* 이제야 구현해 보는 한글 오토마타
* 재미로 해보는 복고풍 한글 구현
* 한달 동안의 사이드 프로젝트
* osx 기본 한글 두벌식 기준

## 목표가 아닌 것

* 수익모델 (정말?)
* 기본 두벌식 외 자판 지원

## 개발 환경

Vue 3, Vue Router 5, Vite 8, Vitest 5를 사용합니다. Node.js 26과 npm 11에서 빌드 및 단위 테스트를 확인했습니다.

## 설치
```
npm ci
```

같은 작업을 `make install`, `make run`, `make test`, `make build`로도 실행할 수 있습니다. 전체 검증은 `make check`를 사용하세요.

### 개발 서버
```
make run
```

브라우저에서 `http://127.0.0.1:8081/`에 접속하세요. 서버를 종료하려면 터미널에서 `Ctrl+C`를 누릅니다. `make dev`도 같은 명령입니다.

### 프로덕션 빌드
```
npm run build
```

빌드 전에 `vue-tsc`로 타입을 검사합니다. 결과는 `dist/`에 생성되며 PWA 서비스 워커도 포함됩니다. 현재 `docs/`에는 과거 GitHub Pages 배포 빌드가 들어 있습니다.

### 단위 테스트
```
npm test
```

`npm run typecheck`로 타입 검사만 실행할 수 있습니다.

## 글꼴 편집

첫 화면에서 초성(8벌), 중성(4벌), 종성(4벌)의 자소를 선택합니다. 16×16 원본, 2배 확대 후 대각선 계단만 메우고 90도 모서리는 유지한 32×32 비트맵, 그 결과의 경계에 약한 3×3 필터를 적용한 32×32 8비트 알파 글꼴을 나란히 편집합니다. 8비트 판은 불투명도 슬라이더에서 0~255 값을 선택해 픽셀마다 칠할 수 있습니다. 수동으로 수정한 단계는 자동 갱신에서 제외되며, 각 판의 `다시 생성` 버튼으로 이전 단계에서 재생성할 수 있습니다. `전체 다시 생성`은 수동 수정분을 포함한 348개 자소의 32×32와 8비트 글꼴을 16×16 원본에서 다시 만들며 되돌리기를 지원합니다.

세 판 모두 클릭·드래그로 그리고 오른쪽 클릭이나 지우기 도구로 지울 수 있습니다. 되돌리기·다시하기를 지원하며, 아래 미리보기는 글꼴을 프로젝트의 `벌식` 규칙대로 조합합니다. 한 글자와 본문 미리보기에서 자소 색상과 검은색 단색을 함께 보여줍니다. 한 글자 비교는 확대 보기이고 본문은 글꼴 픽셀 한 칸을 화면 CSS 픽셀 한 칸으로 그려 실제 크기를 비교합니다. 자소를 선택하거나 편집하면 그 자소를 사용하는 글자가 조합 미리보기에 자동으로 표시됩니다.

본문 아래에는 기기 픽셀 비율(DPR)에 맞춰 32×32 비트맵과 8비트 글꼴을 물리 픽셀 1:1로 표시하는 비교 미리보기가 있습니다. DPR 2 화면에서는 32픽셀 글자가 16 CSS 픽셀 폭으로 보입니다. 글꼴 데이터는 바뀌지 않습니다.

편집 내용은 브라우저에 자동 저장됩니다. 이전 버전의 자동 생성 자소는 현재 계단 메우기 규칙과 약한 안티앨리어싱으로 다시 만들고, 수동 작업은 보존합니다. `불러오기`는 16×16·32×32 `.fnt`와 8비트 `.json` 파일을 받습니다. 16×16과 32×32 저장은 348자소 비트맵 `.fnt`를, 8비트 저장은 348자소의 0~255 알파 배열이 담긴 JSON을 내보냅니다. 기존 타자 연습은 `/practice`에서 열 수 있습니다.

## 키별 자소 마스크 편집

`/masks`에서 두 키로 완성되는 겹모음 7종과 겹받침 11종의 4벌씩, 총 72개 마스크를 16×16 원본 픽셀 기준으로 편집합니다. 파란색은 첫 키, 주황색은 둘째 키에 속한 픽셀입니다. 첫 키의 마스크만 저장하며 둘째 키 영역은 완성 자소 비트맵에서 자동으로 계산합니다. 기본 글꼴이나 글꼴 편집기에 저장한 16×16 원본에서 자동 초안을 만들고, 칠해진 픽셀을 클릭·드래그해 조정할 수 있습니다. 되돌리기·다시하기, 단계별 미리보기, 브라우저 자동 저장, JSON 파일 불러오기·내보내기를 지원합니다. 기존 32×32 마스크는 16×16으로 변환해 불러옵니다.

현재 기본 마스크는 `src/assets/key-masks.json`에 담겨 있습니다. 타자 연습에서는 겹모음·겹받침의 첫 키와 둘째 키 영역을 입력 상태에 따라 따로 칠합니다. 같은 브라우저에서 마스크를 수정했다면 타자 연습을 다시 열거나 `다시하기`를 누르면 저장된 편집본이 적용됩니다. 다른 브라우저에도 기본값으로 배포하려면 편집기에서 내려받은 JSON으로 `src/assets/key-masks.json`을 교체합니다. 타자 연습 글꼴은 현재 앱에 포함된 원본 글꼴을 사용하므로, 글꼴 모양을 변경한 경우에는 마스크가 그 원본 밖으로 벗어나지 않는지 확인해야 합니다.
