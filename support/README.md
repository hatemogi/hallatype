# 글숨 사용 안내와 제안

**글숨**은 좋은 문장을 천천히 따라 쓰는 한글 필사 앱입니다. [dailytyping.com](https://dailytyping.com)에서 바로 사용할 수 있습니다.

이 저장소는 글숨 이용자를 위한 안내와 의견을 모으는 곳입니다. 사용 중 불편한 점을 발견했거나 새로운 글감과 기능을 제안하고 싶다면 [이슈를 남겨 주세요](https://github.com/ohucode/dailytyping/issues/new).

## 시작하기

1. [글숨](https://dailytyping.com)에 접속해 **필사 시작하기**를 누릅니다.
2. **주제 고르기**에서 주제와 글을 선택합니다. 처음이라면 **시작하기** 주제의 짧은 글부터 써 보세요.
3. 화면에 나온 문장을 키보드로 따라 씁니다. 오타가 나면 같은 자리에서 올바른 글자를 다시 입력하면 됩니다.
4. 한 편을 마치면 정타율과 입력 리듬을 볼 수 있습니다. **최근 기록**에서 완성한 글도 다시 살펴볼 수 있습니다.

마음에 드는 글은 별을 눌러 **즐겨찾기**에 모을 수 있습니다. **환경설정**에서는 색상 테마, 글자 크기, 글자 가장자리와 커서 표시를 조정할 수 있습니다. 앱 안의 **도움말**에서도 사용법과 단축키를 볼 수 있습니다.

## 기록은 어디에 저장되나요?

진행 중인 글, 완성 기록, 즐겨찾기와 설정은 현재 사용하는 브라우저에 저장됩니다. 같은 브라우저에서 다시 접속하면 이어 쓸 수 있습니다. 다른 브라우저나 기기에는 기록이 자동으로 옮겨지지 않습니다. 브라우저의 사이트 데이터를 지우거나 시크릿 창을 사용하면 기록이 남지 않거나 사라질 수 있습니다.

기록이 저장되지 않는다는 안내가 나오면 브라우저의 저장 공간과 사이트 데이터 허용 설정을 확인해 주세요.

## 의견 보내기

[이슈 목록](https://github.com/ohucode/dailytyping/issues)에서 같은 내용이 있는지 먼저 확인한 뒤, [새 이슈](https://github.com/ohucode/dailytyping/issues/new)를 작성해 주세요. GitHub 계정 로그인이 필요합니다.

- **오류 제보:** 어떤 화면에서 무엇을 했고 어떤 일이 일어났는지, 사용한 기기·브라우저와 함께 알려 주세요. 가능하면 재현 순서와 화면 사진도 첨부해 주세요.
- **기능 제안:** 어떤 상황에서 필요한 기능인지, 기대하는 동작을 적어 주세요.
- **글감 제안:** 주제, 글의 출처, 이용 허락 여부를 알려 주세요. 타인의 글 전문은 허락 없이 이슈에 붙여 넣지 말아 주세요.
- **사용 질문:** 궁금한 점과 이미 시도한 방법을 적어 주세요.

이슈는 공개됩니다. 이름, 연락처, 계정 정보나 민감한 내용이 보이는 화면 사진은 올리기 전에 가려 주세요. 모든 제안을 바로 반영할 수는 없지만, 내용을 읽고 개선에 참고하겠습니다.

## 빠른 사용 팁

| 키 | 동작 |
| --- | --- |
| `Alt` + `G` | 주제 고르기 |
| `Alt` + `S` | 환경설정 |
| `Alt` + `R` | 이 글 다시 쓰기 |
| `Alt` + `F` | 이 글 즐겨찾기 |
| `Alt` + `H` | 도움말 |
| `Enter` | 한 편을 마친 뒤 다음 글 시작 |

Mac에서는 `Alt`가 `Option(⌥)` 키입니다.

글숨은 소프트웨어 스튜디오 **오후코드**에서 만들었습니다.
